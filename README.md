## Note : 
SQLI no longer uses this type of exams. They now use **LeetCode/HackerRank-style** questions and **multiple-choice questions (MCQs)** focused on DSA and algorithms (in the Java exam).
The exam typically includes three LeetCode-style problems and several multiple-choice questions. You are not required to solve all three problems in order to be selected.
After this exam, there is an interview focused on the Java ecosystem and coding best practices, including:

- SOLID principles
- Design patterns
- Maven
- Spring / Spring Boot
- JPA / ORM / Hibernate
